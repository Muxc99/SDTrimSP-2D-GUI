# 快捷键与常见问题

## 快捷键

| 键 | 用途 |
| --- | --- |
| Ctrl+N / Ctrl+S / Ctrl+Shift+S | 新建 / 保存 / 另存为 |
| Ctrl+C / X / V | 凸起选区复制 / 准备剪切 / 粘贴 |
| Ctrl+Z / Y | 绘图撤销 / 重做 |
| 方向键 / Shift+方向键 | 逐格换选 / 扩选 |
| Alt+拖动 | 按网格移动凸起选区 |
| Delete / F2 / Enter | 删除材料或内部节点 / 编辑所选块 |
| Esc | 取消当前手势、待剪切或基底选择 |

快捷键在对应绘图区生效；文本框内保留正常文本编辑。

## 为什么图没有更新

先检查输入错误与未应用文本，确认编辑的是当前入射组分。单位切换不改变文件值；只切换顶部示例名称也不会载入。旧窗口不会自动热更新程序，保存后重启才使用新代码。

## 为什么不能拖基底

先用选择工具点击基底显示手柄。26 的凸起区优先，需要从 z<0 实体内部选中基底；24/25 基底优先。不能增加节点的几何保持其规则，不任意变成多边形。

## 为什么结果项灰色

对应文件缺失或输出未启用。粒子需 lparticle_p/lparticle_r 与 ioutput_part；轨迹需 ltraj_p/ltraj_r 与 numb_hist 或 ioutput_hist。单个超过 64 MiB 的文件不会自动读取，数据文件页说明原因。格式错误保留旧图并提示，不隐藏失败。

## 遇到内核错误

先查看运行日志末尾和当前运行目录中的 `run.log`，确认错误发生在输入读取、初始化还是计算阶段。再打开运行前检查，核对内核可执行文件格式、运行库目录、材料表文件和案例附件。不要仅凭通用的 `&INPUT` 提示判断输入拼写错误；必要时查看 `tri.inp` 实际内容、换行和 Fortran 运行时错误行号。

GUI 的输入检查只能验证已实现的格式和约束，不能证明所有内核参数组合均有效，也不能替代实际运行。保留失败目录和日志便于定位；修改前不要覆盖原始案例或外部材料表。帮助中标记“待专项数值验证”的行为仍未被确认修复。
