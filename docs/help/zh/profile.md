# 24/25：基底轮廓编辑

## 先选中，再拖动

未选中时不显示节点。选择工具点击基底后，显示上边节点、两侧手柄、底边手柄和底部两个角点；悬停光标提示方向。点击外部或 Esc 取消。24/25 中基底优先，不沿用 26 的凸起格操作。

## 从四边形增加一个节点

1. 初始上边两个端点，加上两个底角，形成闭合矩形。
2. 点击“增加边上节点”，再点击上边线段，插入节点成为五边形。
3. 回到选择工具，拖动该节点到网格交点，改变上表面。
4. 继续增加节点，或删除所选内部节点。两个端点不能删除。

## 侧边、底边与底角

拖动侧边改变居中宽度，上边横坐标随宽度缩放；拖动底边改变 geo_z；底角同时改变宽度与深度。底边始终水平，上表面点不能交叉或降到底边以下。端部角点可以调整端点高度和宽度。尺寸与文件原子更新，支持与节点编辑混合撤销。

## 文件与预览

24 保存为左边界起算坐标，25 保存中心坐标；所有长度为 Å。修改后同步参数、rauh.inp 和预览。原轮廓后附加内容保留。“恢复矩形”重置基础上边为 z=0 两端点，附加余弦参数仍保留。
