# 元素、同位素与成分

## 周期表选择器

元素表中单击元素名或“…”打开周期表选择器；每行“×”删除元素，下方“＋”新增空白行，随后单击“…”选择。元素和材料条目来自用户配置的外部计算内核材料表。确认后使用所选条目，取消不修改。新增空白行必须选择元素后才能保存。

H2 是表内别名，质量与 D 相同；C_g 等是材料变体，不能统称同位素。选择单个条目不会自动展开天然同位素混合物。

## 分数与顺序

| 字段 | 含义 | 约束 |
| --- | --- | --- |
| qu_beam | 入射束流原子分数 | 各组分合计 1；零表示非入射组分 |
| qu_tar | 初始基底原子分数 | 各组分合计 1 |
| qu_max | 动态靶中该组分允许达到的最高原子分数 | 0～1；1 表示不设有限上限 |
| 原子质量 | table1 的相对原子质量 | 大于 0；只作用于当前运行 |
| 质量密度 | table1 的质量密度（g/cm³） | 大于 0；只作用于当前运行 |
| 原子数密度 | table1 的原子数密度（atoms/Å³） | 大于 0；只作用于当前运行 |

`qu_max` 是内核输入参数，不是 `qu_tar` 的别名：`qu_tar` 指初始靶成分，`qu_max` 限制动态靶更新时单个组分可达到的局部原子分数。设为 `1` 表示不设有限上限；`0 < qu_max < 1` 表示指定有限上限。当前 3.01 内核最多支持两个具有有限上限的组分，至少保留一个组分为 `1`。GUI 在输入检查中验证范围和数量，并将值按元素顺序写入 `tri.inp`。非动态靶中此上限不用于动态更新。

质量、质量密度和原子数密度默认从已配置的 `table1` 载入；编辑值只写入本次运行目录的私有材料表副本，并在本次运行输入中启用该副本的数据。源材料表和案例输入不受影响。保存案例不会保存这些材料属性覆盖值。材料属性参考官方报告 §3 与 §10.4.1（印刷页 9–10、44）；参数表 `qu_max` 见 Appendix I.2（印刷页 90）。

能量与角度已移到“靶绘制 → 束流设置”，多个入射组分可分别选择编辑。基底与凸起成分表均按元素顺序排列，凸起可继承基底或单独指定。

## 扩展数组

改变元素数或顺序时，所有按组分排列的高级数组也要对应。存在不同步扩展数组时界面会拒绝操作，请先在输入文本中核对。
