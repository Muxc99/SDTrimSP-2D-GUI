# 网格、基底与单位

## 右侧设置顺序

**网格宽度与间距**：横向 geo_dx、竖向 geo_dz。**基底设置**：当前几何、横向半宽 geo_x、底部 geo_z、粗糙参数。**束流设置**：组分、能量、角度、束斑中心/宽度和起始高度。

## 尺寸示例

| 参数 | 例值（Å） | 对应尺寸 |
| --- | --- | --- |
| geo_x | 200 | 总宽 400 Å = 40 nm，x 从 −200 到 +200 Å |
| geo_z | −200 | 平面参考上边为 0，底部为 −200 Å |
| geo_dx / geo_dz | 25 / 25 | 横向 16 格，参考基底深度 8 格 |

一般二维模式 geo_x 应为 geo_dx 的整数倍；一维模式 geo_dx=2×geo_x，只保留一个横向单元。底边保持水平，宽度关于 x=0 居中。

## 单位速查

| 物理量 | 输入文件单位 | 换算 |
| --- | --- | --- |
| 长度 | Å | 10 Å=1 nm；10000 Å=1 μm |
| 能量 | eV | GUI 与文件均为 eV |
| 角度 | 度 | 0° 沿参考表面法线 |
| 注量 | ions/Å² | 1 ion/Å²=10¹⁶ ions/cm² |
| 原子数密度 | atoms/Å³ | 1 atom/Å³=10²⁴ atoms/cm³ |

顶部单位只切换显示；保存的所有长度仍为 Å。预览横纵物理单位默认等长，这不是要求画布为正方形。
