# 输入文本与高级参数

## 三种编辑入口

表单适合常用参数；“二维结构块”是矩形块明细；“输入文件”可编辑 tri.inp、fig.inp 及已载入辅助文件。三者同步，所有文件长度均为 Å。

## 分层图形编辑

在“靶绘制”的基底成分区或“输入文件”工具栏点击“分层成分编辑”。体分层使用绝对 z 坐标；表面分层使用从局部表面向下的竖直偏移，表面为 0、向下为负。两者独立启用，表面层覆盖对应位置的体分层成分。示意图不是内核网格计算结果。

表格填写上、下边界及按元素顺序排列的原子分数；各层边界须连续、从上到下递减，分数合计为 1。可增加或删除层，也可拖动示意图中的内部边界，拖动按竖向网格对齐。边界使用当前显示单位，写入文件始终使用 Å。点击“应用到靶结构”更新预览，再保存案例写入磁盘。

## 可选文件管理

几何与分层是独立功能：同一几何可以启用或停用分层。添加分层文件会创建有效模板并启用对应开关；停用分层后可以保留文件，也可以移除。tri.inp、stop_run.inp，以及当前几何/分布/模型正在使用的附件受到删除保护。移除文件只修改内存草稿；保存时原文件进入案例下的 .gui-backups，再从案例目录移除。未加载的非输入文件不受影响。

## 应用文本

修改文本后点击“应用文本修改”；切页、保存或运行也会尝试应用有效修改。非法草稿保留，不用旧预览覆盖。修正后再应用，或“撤销未应用文本”返回当前表单内容。

工具栏提供保存（整个案例）、当前文件撤销/重做、添加、导入、移除和查找。Ctrl+S 保存，Ctrl+Z/Ctrl+Y 在文本框中撤销/重做，Ctrl+F 查找。文件名后的 * 表示尚未应用的文本；应用只更新内存模型，仍需保存到磁盘。撤销未应用文本会丢弃当前草稿，和逐步撤销不同。

工具栏使用紧凑图标，悬停 0.5 秒显示说明。查找栏默认收起，点击放大镜或按 Ctrl+F 展开。

## 高级参数

沿用原 Fortran 写法；未编辑扩展项保留原文。组分相关数组必须与元素顺序一致。常见附件：

| 文件 | 用途 |
| --- | --- |
| rauh.inp | 24/25 上表面 |
| energy.inp / angle.inp | 文件分布 |
| initial_composition.inp | 初始体分层 |
| initial_composition_surf.inp | 初始表面分层 |
| mat_surfb.inp | 自定义结合能矩阵 |

不要只新增文件名而遗漏启用参数，也不要删除计算所需附件。高级物理模型应按工况选择，GUI 不自动拟合。
