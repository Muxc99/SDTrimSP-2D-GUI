# 检查、运行与停止

## 运行前

检查元素顺序、束流/基底分数、几何边界、网格、附件和输出开关。错误会阻止保存或运行；提示可能表示内核会特殊处理参数，须自行核对。

## 运行副本

点击运行后，在本地工作目录建立独立目录，用当前有效输入调用用户配置的兼容计算内核。运行日志显示原始诊断，不把错误当成功跳过。没有配置内核时 GUI 不能执行计算。

## 停止与完成

“请求停止”写 stop_run.inp=1，内核按既有间隔检查（每 10 个注量步），不是立即强杀。等待日志确认停止/结束，再载入完整输出；载入本次运行结果在运行结束后使用。

## 科学检查

完成标记、错误文本和 time_run.dat 是完成判断线索；还需检查粒子统计、注量步长、网格与模型适用性。初始示意图不能证明内核运算，短程运行也不代表收敛。



运行时，顶部停止按钮与结果目录按钮之间显示进度。百分比来自内核的注量步输出，更新间隔由内核决定；到达 100% 后仍需检查结束标记与输出文件，检查通过才显示“运行成功”。“运行失败”时请查看日志；“已停止”表示响应了停止请求，结果可能不完整。
