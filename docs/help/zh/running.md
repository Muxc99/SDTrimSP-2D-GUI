# 检查、运行与停止

## 安装与设置

Windows 安装包和便携包已包含 Python、PySide6、NumPy、pandas 和 Matplotlib，双击 SDTrimSP-2D_GUI.exe 或快捷方式启动，无需另装依赖。源码版双击 start-gui.cmd，首次会自动安装依赖（需联网）。

顶部电脑图标打开“内核与数据设置”。分别选择已编译的内核程序、材料表目录和结果目录，可在不同磁盘。扫描只列出候选项，需手动确认。没有固定盘符要求，不需要额外 run-case 脚本，也不要求材料表位于 work/tables。

程序按文件头区分 Linux ELF 和 Windows PE，不能只看 .exe 后缀。Linux 内核在 Windows 上需 WSL 及对应依赖；Windows x64 内核需对应 Windows 运行库。WSL 发行版留空时使用系统默认发行版。可跳过设置继续编辑与查看已有结果。

Windows 内核的 DLL 不必与程序放在同一目录。“Windows 运行库目录”可选择内核配套的 `ucrt64/bin`、`mingw64/bin` 或其他 DLL 文件夹；留空自动识别附近目录，发现多套运行库时需明确选择。运行前检查与实际计算使用同一套目录，不修改系统全局 PATH。若仍报错，检查提示的依赖链与 Windows 错误码；文件存在也可能因缺少下级依赖或位数不匹配而无法加载。Linux 内核不使用此设置。

## 运行前检查

检查组分顺序、原子分数、几何、网格、辅助输入和输出开关。点击运行后显示当前输入位置、内核程序和格式、材料目录、所需表文件、运行库检查、结果目录，逐项指出缺项。不推测内核版本；未报告的版本明确显示“未声明”。更改配置后可重新检查。

## 独立结果目录

默认结果位于当前用户“文档 / SDTrimSP-2D / Runs”，也可改为其他可写目录。每次创建独立文件夹，保存当前输入与所选材料目录的副本。只将运行副本的 tableinp 改成 ./_tables；原案例和内核安装目录不修改。运行目录含私人材料数据，不要跟 GUI 一起公开上传。

## 停止与完成

请求停止写入 stop_run.inp=1，内核按既有间隔检查。等待日志显示结束，再载入完整结果。现有进度条和结束判定保留原有行为。

## 关于与诊断

“关于与诊断”显示 GUI、Python、Qt 版本，以及内核格式和 SHA-256 指纹。无法确定的内核版本显示未声明。导出的 JSON 不包含用户名、路径、输入内容或运行日志，用于确认 GUI 构建和材料文件缺项。

## 科学检查

运行成功不代表统计收敛或物理适用性已验证。需另外检查注量、网格、统计量和模型。初始预览不是内核运算结果。
