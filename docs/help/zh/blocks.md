# 26：绘制与编辑凸起块

## 默认操作凸起

26 模式中，材料格和空白格的选择、画笔、橡皮擦、矩形、右键和复制粘贴优先。基底逻辑优先级最低；先在 z<0 基底内部选中才显示手柄。回到凸起区或切换绘制工具即取消基底选择，不能拦截 z≥0 空白网格。

## 工具与成分

| 工具 | 操作 |
| --- | --- |
| 选择 | 单击整格，拖动框选；Ctrl 多选，方向键换格 |
| 画笔 | 按住涂绘整格，采用右侧凸起成分 |
| 矩形 | 拖出范围，自动按网格拆分，保留边缘不满格 |
| 橡皮擦 | 删除经过的整个凸起块，不擦除基底 |
| 平移 | 拖动画面；中键也可平移，滚轮缩放 |

“凸起成分（原子分数）”可采用基底或所选块成分。勾选逐块成分后写入 fig.inp；关闭时使用基底成分。画笔和矩形绘制遇到已有网格时默认替换该格材料。

## 编辑、移动与剪贴板

右键编辑尺寸/成分、整体改材料、填充空白格或移动。Alt+拖动按网格移动；Ctrl+C/X/V 复制/准备剪切/粘贴。剪切只有成功粘贴才删除源位置。空白格保留选区相对布局，不生成虚假材料。镜像打开时两侧联动，右半区绘制。冲突或越界整次拒绝。

## 基底尺寸与撤销

选中基底后拖动侧边/底角改变宽深；已有凸起块不缩放，缩窄导致块越界时拒绝。Ctrl+Z/Y 撤销重做。手工修改表格或网格可能清空旧绘图历史。


## 大量色块的显示

大量完整网格色块使用批量栅格显示，局部格保留精确矩形边缘；这只改变显示方式，不合并或减少 fig.inp 中的材料块。缩小到单格不足 3 像素时自动隐藏材料格细边线，放大后恢复，背景网格仍由“显示网格”控制。选择与画笔预览独立刷新，颜色渐变仍可实时调整。
