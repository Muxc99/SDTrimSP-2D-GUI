# 几何类型与轮廓文件

## 模式对照

| case_geo | 靶结构 | 主要输入 |
| --- | --- | --- |
| 10 | 一维平面 | geo_x、geo_z；横向单格 |
| 20 | 二维平面 | 网格与基底尺寸 |
| 24 | 折线上表面，文件从左边界起算 | rauh.inp：通常 x=0～总宽 |
| 25 | 折线上表面，文件使用中心坐标 | rauh.inp：通常 x=−geo_x～+geo_x |
| 26 | 平面基底＋矩形材料块 | fig.inp |
| 27 | 余弦表面 | pr_amp、pr_wl |

几何类型在新建时选择，靶绘制显示当前编号和名称。24/25 的 GUI 画布统一使用中心坐标；保存时转换文件坐标。

## rauh.inp 最小示例

模式 24、总宽 400 Å：

~~~text
surface profile
3
0    0
200  50
400  0
~~~

对应模式 25 的横坐标为 −200、0、200。点按 x 严格递增，相邻点线性插值，覆盖完整靶宽。文件只定义上表面，底部仍为 geo_z；只能表达单值 z(x)，不能直接表达洞穴、悬空回折。

## 余弦表面

z(x)=pr_amp×[1−cos(2πx/pr_wl)]，峰谷差为 2×pr_amp。24/25 也可叠加相关余弦项；不要把橙色基础轮廓与叠加后的表面混同。
