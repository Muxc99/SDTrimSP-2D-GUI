# 新建、打开与保存

## 新建案例

启动是尚未保存的空白案例。Ctrl+N 打开新建窗口：选择几何类型，点击入射/基底元素按钮打开周期表，再填写名称、尺寸、网格与束流。初始参数是建模起点，请按工况修改。新建 24/25 自动生成平面 rauh.inp；26 初始无凸起。

案例标题在主窗口顶部直接修改。新建会询问是否放弃已有未保存修改；取消保留当前案例。

## 文件去向

| 操作 | 写入位置 | 之后的当前路径 |
| --- | --- | --- |
| 保存 Ctrl+S | 当前案例目录；首次保存选择新目录 | 保存目录 |
| 另存为 Ctrl+Shift+S | 新目录 | 切换至新目录 |
| 运行 | 本地工作目录中的独立运行副本 | 输入案例路径保持 |

覆盖修改过的输入前自动备份；原计算输出不作为输入覆盖。另存为保留辅助输入。案例由用户自行提供。

## 打开已有案例

点击“打开案例”并选择包含 tri.inp 的目录。载入后检查几何、元素顺序、单位与附件。
