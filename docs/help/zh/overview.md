# SDTrimSP-2D_GUI v1.0.0

这是现有 Fortran 内核的输入编辑、靶结构绘制与结果查看界面。左侧目录选择主题；搜索框可检索标题、正文和参数名，右侧“本页目录”跳到对应小节。文档可复制为 Markdown，完全离线可读。

## 第一次使用

1. 点击顶部“新建”，选择几何类型、入射元素和基底元素，填写尺寸与束流条件。
2. 在“元素”页设置束流与基底原子分数，在“靶绘制”页设置网格、基底和束流。
3. 模式 26 绘制凸起块；24/25 编辑上表面轮廓。
4. 检查输入并保存，再运行。计算结束后载入同一案例的输出目录。

## 页面导航

| 页面 | 用途 |
| --- | --- |
| 参数设置与预览 | 元素、成分、计算模式和初始靶预览 |
| 靶绘制 | 网格/基底/束流、凸起材料及轮廓操作 |
| 二维结构块 | fig.inp 矩形块数值明细 |
| 高级参数 / 输入文件 | 扩展项及原始文本 |
| 运行日志 / 结果绘图 | 计算进度与已有输出 |

## 如何理解帮助中的依据

帮助区分三类信息：界面当前行为、SDTrimSP-2D 3.01 源码/官方报告确认的规则，以及尚未专项验证的限制。凡写“本机内核”均指本开发机所核对的 3.01 源码，不代表用户配置的任意内核版本。官方报告章节和页码采用 PDF 印刷页码；帮助只引用必要内容，不捆绑报告或内核。

主要参考：报告 §2（几何，印刷页 5–8）、§3 与 §10.4.1（组分上限，页 9–10、44）、§8（网格分辨率，页 25）、§10.1–10.3（尺寸、几何、入射起点，页 28–41）、§10.4（初始化、分层与团簇，页 44–48）；Appendix A（单位，页 70）、D（高斯分布，页 74）、E（输入/输出，页 75–77）、F（分布文件，页 78–79）和 I（参数，页 83–90）。引用用于解释输入含义，不替代与实际内核版本匹配的手册。
