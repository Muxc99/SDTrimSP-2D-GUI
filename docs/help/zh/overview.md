# SDTrimSP-2D_GUI v0.9.0

这是现有 Fortran 内核的输入编辑、靶结构绘制与结果查看界面。左侧目录选择主题；搜索框可检索标题、正文和参数名，右侧“本页目录”跳到对应小节。文档可复制为 Markdown，完全离线可读。

## 第一次使用

1. 点击顶部“新建”，选择几何类型、入射元素和基底元素，填写尺寸与束流条件。
2. 在“元素”页设置束流与基底原子分数，在“靶绘制”页设置网格、基底和束流。
3. 模式 26 绘制凸起块；24/25 编辑上表面轮廓。
4. 检查输入并保存，再运行。计算结束后载入同一案例的输出目录。

## 页面导航

| 页面 | 用途 |
| --- | --- |
| 参数设置与预览 | 元素、成分、计算模式和初始靶预览 |
| 靶绘制 | 网格/基底/束流、凸起材料及轮廓操作 |
| 二维结构块 | fig.inp 矩形块数值明细 |
| 高级参数 / 输入文件 | 扩展项及原始文本 |
| 运行日志 / 结果绘图 | 计算进度与已有输出 |
