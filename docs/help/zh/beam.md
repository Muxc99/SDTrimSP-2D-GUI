# 束流、能量与角度

## 参数在哪里

“靶绘制 → 束流设置”编辑能量和角度。多个 qu_beam>0 的组分可分别选择，预览箭头跟随所选入射组分，尖端横坐标对应 x_start。能量/角度数组仍按“元素”顺序保存。

| 参数 | 含义 |
| --- | --- |
| x_start / dx_start | 束斑中心 / 宽度 |
| z_start | 部分起点模式的入射起始高度 |
| case_start | 起点抽样规则；1 从局部表面起射，3 固定坐标，4 随机束斑 |
| e0_beam / alpha0 | 含义由下面的分布模式决定 |

case_start=1 时 z_start 不是实际起射高度。束宽过小等条件可能触发内核全宽处理，请读检查提示。

## 能量模式

| 编号 | 名称 | 含义 |
| --- | --- | --- |
| 0 | 固定能量 | 使用各入射组分的 e0_beam 作为固定能量，单位 eV。 |
| 1 | 能量文件 | 从 energy.inp 读取并抽样能量分布；不是固定能量。能量单位为 eV。 |
| 2 | 三维麦克斯韦 | 三维麦克斯韦热运动，加上鞘层加速（charge × shth）。e0_beam 是温度能量尺度 kT（eV），不是固定粒子能量。本模式会重新计算入射方向，不能与角度模式完全独立理解。 |
| 3 | 简化麦克斯韦 | 简化麦克斯韦模式，调用 energ；本机实现的入射方向限制在 x–z 平面。e0_beam 是温度能量尺度 kT（eV），并考虑鞘层加速；本模式会重新计算方向。 |
| 5 | 高斯能量 | 高斯能量分布：中心为 e0_beam，标准差为 de0_beam，单位 eV。本机内核在中心 ±4σ 内抽样，并排除负能量；de0_beam 需为正。 |

## 角度模式

| 编号 | 名称 | 含义 |
| --- | --- | --- |
| 0 | 固定角度 | 使用各入射组分的 alpha0 作为固定入射角，单位为度；相对参考表面法线，0° 为垂直入射。能量模式 2/3 会重新计算方向。 |
| 1 | 极角均匀 | 极角在 0～alpha0 之间均匀抽样，方位角随机。alpha0 为角度上限（度），不是分布中心；这不是立体角均匀分布。 |
| 2 | 余弦通量 | 内置余弦通量分布：极角为 0～90°，方位角随机。按极角统计时，概率密度在 45° 附近最大；不由 alpha0 指定中心。 |
| 3 | 小角偏重 | 内置小角度偏重分布：极角为 0～90°，方位角随机，靠近法线的小角度较多；与模式 2 的余弦通量分布不同。 |
| 4 | 角度文件 | 从 angle.inp 读取角度分布，角度单位为度。注意：本机源码抽样 alpha_pol 后，坐标转换却使用 alpha_z，疑似变量错误；尚未专项数值验证或修复，使用前需核实。 |
| 5 | 高斯角度 | 高斯角度分布：中心为 alpha0，标准差为 dalpha0，单位为度。本机在中心 ±4σ 内抽样，并限制到 −180～180°；dalpha0 需为正。 |

## 使用时核对

0° 为沿参考表面法线入射。角度文件或内置分布模式下，单个 alpha0 不控制实际角度，因此快捷框禁用并说明原因。能量模式 2/3 会重算方向，不能认为能量与角度模式总是独立。箭头是示意，不显示实际抽样分布。

角度模式 4 的本机源码疑似使用了不一致变量，尚无专项数值验证；帮助不把它认定为已修复。
