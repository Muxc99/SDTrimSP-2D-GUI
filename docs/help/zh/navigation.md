# 绘图交互与数据导出

## 鼠标与工具栏

| 动作 | 效果 |
| --- | --- |
| 左键拖动 / 中键拖动 | 平移（框选/数据工具另有用途） |
| 光标处滚轮 | 以鼠标位置为中心缩放 |
| 框选放大 | 拖矩形放大 |
| 双击 / 显示全部 | 恢复全部数据范围 |
| 后退 / 前进 | 恢复先前视图 |
| 数据查看 | 显示记录的单元/曲线值，空白处标记光标坐标 |

图标悬停 0.5 秒显示说明；初始靶预览与结果绘图共用交互。初始预览不是计算结果。

## 坐标与比例

默认横纵物理单位长度 1:1，z=0 居中；这不要求画布为正方形。居中菜单可选靶表面。“坐标设置”调整范围、比例、标题、网格和刻度，可解除比例锁定。比例快捷按钮已删除，设置仍保留。

## 导出与历史步

“数据表”在独立浮窗中显示当前图的完整只读数据，不压缩绘图区。拖选、Shift 扩选或 Ctrl 多选；Ctrl+C 复制选区，Ctrl+A 全选，也可右键或点“复制（含列名）”。复制的数据按行列分隔，可直接粘贴到 Excel 等软件，保留数值精度。CSV 导出完整当前图数据。 轨迹条数与直方图分箱按当前选项。CSV 中 _A 坐标列和 fluence_ions_A2 保留原始单位。PNG 保存当前图；GIF 按钮已移除。多历史步可播放/拖动滑块，固定色标便于对比。


## 自定义颜色渐变

二维原子分数、元素数密度和总数密度图可点击绘图工具栏中的“颜色渐变”图标（保存图片左侧），也可双击右侧色条进入。初始靶预览支持同样的两个入口；靶绘制页可双击绘图区或原子分数色条进入。初始靶预览与靶绘制页按元素共享配色，结果页独立设置。

拖动四个色标调节渐变位置；双击色标或点击“色标颜色…”选择颜色，也可输入位置百分比。颜色实时预览，确定保留，取消恢复。位置表示色标数值范围内的百分比，不改变数据、上下限或坐标。配色在当前窗口内保留。

当前窗口中同一图种和组分的配色在切换历史步后保留，PNG导出使用该配色；CSV数值不变。无色条的曲线图不启用此按钮。
